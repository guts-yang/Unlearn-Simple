# SimNPO 实验复现指南（2×A800-80GB）

本文档面向 **2 张 A800-80GB** 的机器，说明如何从零复现本仓库的四个子项目。目标：远程 `git pull` 后按步骤即可开跑。言简意赅，只列必要细节。方法本身的公式与代码对照见 [方法原理](方法原理.md)。

**推荐复现顺序：synthetic → TOFU → MUSE → WMDP**（由易到难、由快到慢：synthetic 分钟级验证环境，TOFU 为主实验，MUSE/WMDP 需额外数据或更长时间）。

---

## 0. 获取代码并切换分支

本次实验的改动在分支 `feature/chenyliao_20260806`。远程机器首次拉取：

```bash
git clone https://github.com/guts-yang/Unlearn-Simple.git
cd Unlearn-Simple
git checkout feature/chenyliao_20260806
```

已克隆过、只需切分支并更新：

```bash
git fetch origin
git checkout feature/chenyliao_20260806
git pull origin feature/chenyliao_20260806
```

## 1. 硬件与环境

- GPU：2×A800-80GB（7B 模型最少 2 张；1 张易 OOM）
- 镜像：PyTorch 2.8 / Python 3.12 / CUDA 12.8（可直接复用，不必降级到 CUDA 11.8）
- 磁盘：**系统盘仅 ~30GB，模型与缓存必须放数据盘**
- 显存占用（TOFU 训练）：约 55GB/卡；评估阶段峰值更高，已把 eval batch 调到 8

## 5. synthetic（先跑，验证环境，单卡/分钟级）

数据本地生成、模型自建，无需下载任何权重。`run_synthetic.sh` 中命令默认全部注释，按下列顺序在 `synthetic/` 目录手动执行：

```bash
cd synthetic

# 1) 生成合成数据
python generate_data.py --data_dir data --seed 42

# 2) 训练 pretrain 与 retain 参照模型
python train.py --model_type pretrain --data_dir data --epochs 5 --batch_size 128
python train.py --model_type retain   --data_dir data --epochs 5 --batch_size 128

# 3) 遗忘（loss_type 可选 NPO / SimNPO / grad_diff / grad_ascent / kl 等）
python unlearn.py --loss_type SimNPO --beta 1.0 --data_dir data \
  --unlearning_epochs 1 --max_iterations 50 --batch_size 4 --learning_rate 5e-4

# 4) 评估 / 绘图
python evaluate.py --model_type retain --data_dir data
python plot_evaluation.py --loss_type SimNPO --data_dir data
```

单卡即可（默认 `cuda:0`，加 `--no_cuda` 退回 CPU）。`unlearn.py` 支持的 `loss_type` 见 `unlearn_utils.py`：`NPO`、`NPO_KL`、`NPO_RT`、`SimNPO`、`SimNPO_KL`、`SimNPO_RT`、`grad_diff`、`grad_ascent`、`kl` 等。

## 6. TOFU 主实验（2 卡）

### 6.1 下载起点模型

```bash
export HF_HOME=/data/hf_cache
hf auth login                            # 见第 4 节

# 遗忘起点模型（~13GB，主实验唯一必需）
hf download locuslab/tofu_ft_llama2-7b \
  --local-dir /data/models/tofu_ft_llama2-7b
# tokenizer / 基座（若受限可跳过，见第 10 节）
hf download NousResearch/Llama-2-7b-chat-hf \
  --local-dir /data/models/Llama-2-7b-chat-hf
```

PowerShell 请写成单行（不要用 `\` 续行）：

```powershell
hf download locuslab/tofu_ft_llama2-7b --local-dir D:\models\tofu_ft_llama2-7b
```

备选：从作者 [Google Drive](https://drive.google.com/drive/folders/1L47Hf813gal8RD581S3XrWHnY_0ll4y4?usp=sharing) 下载 origin 模型。

> `forget.py` 用 `os.listdir(model_path)` 判断权重，**`model_path` 必须是本地目录，不能填 HF 仓库名**。

### 6.2 安装依赖

```bash
cd TOFU
pip install -r requirements.txt
pip install flash-attn --no-build-isolation   # 若编译失败，见第 9 节
```

### 6.3 关键配置（`TOFU/config/forget.yaml`，已改好）

| 项 | 值 | 说明 |
|----|----|------|
| `model_path` | `/data/models/tofu_ft_llama2-7b` | 按需改成你的本地路径 |
| `batch_size` | 1 | 不变 |
| `gradient_accumulation_steps` | **16** | 2 卡下 `1×16×2=32`，与论文 8 卡 `1×4×8=32` 一致 |
| `num_epochs` | 10 | 不变 |
| `lr` | 1e-5 | 不变 |
| `forget_loss` | `simnpo_grad_diff` | SimNPO 主方法 |
| `eval.batch_size` | **8** | 由 30 降低，防评估 OOM |

> `num_epochs` 决定数据过几遍；全局 batch = `batch_size × accum × 卡数`。用 `accum=16` 保持全局 batch=32，使优化步数与论文一致。

### 6.4 运行（每次只跑一个场景）

```bash
cd TOFU
export HF_HOME=/data/hf_cache

bash run_simnpo.sh forget05      # 默认即 forget05，可省略参数
# 查看结果满意后再跑：
bash run_simnpo.sh forget10
```

脚本默认 `CUDA_VISIBLE_DEVICES=0,1`、`nproc_per_node=2`、`master_port=29500`，可用环境变量覆盖；`npo_coeff`/`beta` 按 split 自动选择。等价手动命令：

```bash
# forget05
CUDA_VISIBLE_DEVICES=0,1 torchrun --nproc_per_node=2 --master_port=29500 \
  forget.py --config-name=forget.yaml split=forget05 npo_coeff=0.1375 beta=2.5
# forget10
CUDA_VISIBLE_DEVICES=0,1 torchrun --nproc_per_node=2 --master_port=29500 \
  forget.py --config-name=forget.yaml split=forget10 npo_coeff=0.125 beta=4.5
```

### 6.5 结果

- 遗忘后模型与评估写入 `${save_dir}/`（目录名带 `2GPU_` 前缀，位于 `model_path/unlearned/` 下）
- 汇总指标：`${save_dir}/checkpoint/aggregate_stat.txt`

## 7. MUSE（Books / News 遗忘，2 卡）

代码已在本仓库 `MUSE/`，目标模型与数据来自 `muse-bench`。

### 7.1 环境与数据

```bash
cd MUSE
conda env create -f environment.yml      # Python 3.10
conda activate muse

export HF_HOME=/data/hf_cache
python load_data.py                       # 从 muse-bench 拉取 News/Books 数据到 MUSE/data/
```

### 7.2 运行 unlearning（SimNPO+GDR，论文设定）

tokenizer 用公开镜像 `NousResearch/Llama-2-7b-hf`，避开门控的 `meta-llama/Llama-2-7b-hf`：

```bash
cd MUSE/baselines

# News
CUDA_VISIBLE_DEVICES=0,1 python unlearn.py --algo simnpo_gdr \
  --model_dir muse-bench/MUSE-News_target \
  --tokenizer_dir NousResearch/Llama-2-7b-hf \
  --data_file ../data/news/raw/forget.txt \
  --retain_data_file ../data/news/raw/retain1.txt \
  --out_dir ./ckpt/news/simnpo_gdr \
  --max_len 2048 --epochs 10 --lr 1e-5 \
  --per_device_batch_size 4 --beta 0.7 --coeff 0.1 --npo_coeff 1.0

# Books
CUDA_VISIBLE_DEVICES=0,1 python unlearn.py --algo simnpo_gdr \
  --model_dir muse-bench/MUSE-Books_target \
  --tokenizer_dir NousResearch/Llama-2-7b-hf \
  --data_file ../data/books/raw/forget.txt \
  --retain_data_file ../data/books/raw/retain1.txt \
  --out_dir ./ckpt/books/simnpo_gdr \
  --max_len 2048 --epochs 10 --lr 1e-5 \
  --per_device_batch_size 4 --beta 0.75 --coeff 0.1 --npo_coeff 1.0
```

`--algo` 可选：`simnpo`、`simnpo_gdr`、`ga`、`ga_gdr`、`ga_klr`、`npo`、`npo_gdr`、`npo_klr`、`tv`。结果模型保存在 `MUSE/baselines/ckpt/<corpus>/<algo>/checkpoint-*`。

> 80GB 显存下 `per_device_batch_size=4` 可保持论文设定；若 OOM 可降到 2。

### 7.3 评估

```bash
cd MUSE
python eval.py \
  --model_dirs "baselines/ckpt/news/simnpo_gdr/checkpoint-<最后一个>" \
  --names "simnpo_gdr" \
  --corpus news \
  --tokenizer_dir NousResearch/Llama-2-7b-hf \
  --out_file out_news.csv
```

论文取 epoch 10 的 simnpo 结果。指标：`verbmem_f`、`privleak`、`knowmem_f`、`knowmem_r`（Utility）。

## 8. WMDP（Zephyr-7B 生物知识遗忘，2 卡）

1. 环境（Linux）：

```bash
conda env create -f WMDP/environment.yml
conda activate wmdp
```

2. 数据（`WMDP/files/` 被 gitignore，必须手动放）：

- 从 [WMDP 官方](https://github.com/centerforaisafety/wmdp) 申请并下载 WMDP-Bio 遗忘语料到 `WMDP/files/data/bio_remove_dataset.jsonl`
- 拒答语料放到 `WMDP/files/data/polite_refusal_responses/polite_refusal_responses.csv`
- 评测集 `cais/wmdp`、`cais/wmdp-corpora`、`wikitext` 与 Zephyr-7B 运行时自动下载

3. 运行（已改为 2 卡，单进程 `device_map=auto` 自动分片）：

```bash
cd WMDP
export HF_HOME=/data/hf_cache
bash run_wmdp_unlearn.sh
```

配置在 `WMDP/configs/unlearn/wmdp/`，4 个方法：`SimNPO.json`（主方法）、`NPO.json`、`GradDiff.json`、`Relearn+Forget.json`（重学习鲁棒性）。默认脚本只跑 `SimNPO`；跑其它方法改脚本里的 `--config-file`。`SimNPO.json` 关键项：`lr=9.5e-6`、`max_steps=500`、`beta=0.1`、`gamma=1.0`。结果在 `WMDP/files/results/unlearn_wmdp_bio/<方法名>`。

## 9. 常见问题

- **flash-attn 编译失败**：把 `TOFU/config/model_config.yaml` 中 `llama2-7b.flash_attention2` 设为 `"false"`（可跑，略慢）。
- **评估阶段 OOM**：下调 `forget.yaml` 的 `eval.batch_size`（如 4）；MUSE 下调 `--per_device_batch_size`。
- **磁盘写满**：确认 `HF_HOME` 与模型都在数据盘，而非 30GB 系统盘。
- **model_path 报错找不到目录**：必须是本地目录，不能填 HF 仓库名。

---

## 10. Llama-2 访问受限（申请被拒）怎么办

被拒的通常是 Meta 官方 `meta-llama/Llama-2-...`，**本仓库不需要它**：

- TOFU 起点 `locuslab/tofu_ft_llama2-7b` 公开且**自带 tokenizer**；若 `NousResearch/Llama-2-7b-chat-hf` 也下不了，把 `TOFU/config/model_config.yaml` 的 `llama2-7b.hf_key` 改成本地已下载目录即可。
- MUSE 的 `--tokenizer_dir` 用公开镜像 `NousResearch/Llama-2-7b-hf` 替代 `meta-llama/Llama-2-7b-hf`。

---

## 11. 时间预估

相较论文 8 卡，2 卡吞吐约为其 1/4，墙钟时间约 **4 倍**。用 `accum=16` 对齐全局 batch 不会显著增加耗时，主要瓶颈是卡数。synthetic 分钟级；TOFU/MUSE/WMDP 均为 7B 模型、单机 2 卡，耗时同量级。
