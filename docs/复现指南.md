# SimNPO 实验复现指南（2×A800-80GB）

本文档面向 **2 张 A800-80GB** 的机器，说明如何从零复现本仓库主实验。目标：远程 `git pull` 后按步骤即可开跑。言简意赅，只列必要细节。

---

## 1. 硬件与环境

- GPU：2×A800-80GB（最少 2 张；1 张易 OOM）
- 镜像：PyTorch 2.8 / Python 3.12 / CUDA 12.8（可直接复用，不必降级到 CUDA 11.8）
- 磁盘：**系统盘仅 ~30GB，模型与缓存必须放数据盘**
- 显存占用（TOFU 训练）：约 55GB/卡；评估阶段峰值更高，已把 eval batch 调到 8

## 3. HuggingFace 预配置（TOFU 前必做）

实验加载两类资源：


| 用途                       | HF 仓库                                                                                       | 说明                  |
| ------------------------ | ------------------------------------------------------------------------------------------- | ------------------- |
| 遗忘起点权重（`model_path`）     | `[locuslab/tofu_ft_llama2-7b](https://huggingface.co/locuslab/tofu_ft_llama2-7b)`           | 公开，**必须下载为本地目录**    |
| tokenizer / 基座（`hf_key`） | `[NousResearch/Llama-2-7b-chat-hf](https://huggingface.co/NousResearch/Llama-2-7b-chat-hf)` | 可能需同意 Llama-2 许可    |
| 数据集                      | `[locuslab/TOFU](https://huggingface.co/datasets/locuslab/TOFU)`                            | forget01/05/10 自动下载 |


> 注意：`forget.py` 用 `os.listdir(model_path)` 判断权重，`**model_path` 不能写成 HF 仓库名**，必须是本地目录。

```bash
pip install -U "huggingface_hub[cli]"
export HF_HOME=/data/hf_cache            # 指向数据盘
export HUGGINGFACE_HUB_CACHE=$HF_HOME
huggingface-cli login                    # 粘贴 Read Token

# 遗忘起点模型（~13GB）
huggingface-cli download locuslab/tofu_ft_llama2-7b \
  --local-dir /data/models/tofu_ft_llama2-7b
# tokenizer / 基座
huggingface-cli download NousResearch/Llama-2-7b-chat-hf \
  --local-dir /data/models/Llama-2-7b-chat-hf
```

备选：从作者 [Google Drive](https://drive.google.com/drive/folders/1L47Hf813gal8RD581S3XrWHnY_0ll4y4?usp=sharing) 下载 origin 模型到本地。

## 5. TOFU 主实验

### 关键配置（`TOFU/config/forget.yaml`，已改好）


| 项                             | 值                                | 说明                                     |
| ----------------------------- | -------------------------------- | -------------------------------------- |
| `model_path`                  | `/data/models/tofu_ft_llama2-7b` | 按需改成你的本地路径                             |
| `batch_size`                  | 1                                | 不变                                     |
| `gradient_accumulation_steps` | **16**                           | 2 卡下 `1×16×2=32`，与论文 8 卡 `1×4×8=32` 一致 |
| `num_epochs`                  | 10                               | 不变                                     |
| `lr`                          | 1e-5                             | 不变                                     |
| `forget_loss`                 | `simnpo_grad_diff`               | SimNPO 主方法                             |
| `eval.batch_size`             | **8**                            | 由 30 降低，防评估 OOM                        |


> 全局 batch 与 epoch：`num_epochs` 决定数据过几遍；全局 batch = `batch_size × accum × 卡数`。用 `accum=16` 保持全局 batch=32，使优化步数（`max_steps`）与论文一致。

### 一键运行

```bash
cd TOFU
export HF_HOME=/data/hf_cache
bash run_simnpo.sh          # 依次跑 forget05 与 forget10
```

脚本默认 `CUDA_VISIBLE_DEVICES=0,1`、`nproc_per_node=2`、`master_port=29500`，可用环境变量覆盖。

### 手动运行（等价）

```bash
export master_port=29500
export HF_HOME=/data/hf_cache

# forget05
CUDA_VISIBLE_DEVICES=0,1 torchrun --nproc_per_node=2 --master_port=$master_port \
  forget.py --config-name=forget.yaml split=forget05 npo_coeff=0.1375 beta=2.5

# forget10
CUDA_VISIBLE_DEVICES=0,1 torchrun --nproc_per_node=2 --master_port=$master_port \
  forget.py --config-name=forget.yaml split=forget10 npo_coeff=0.125 beta=4.5
```

论文主设定：forget05 → `npo_coeff=0.1375 beta=2.5`；forget10 → `npo_coeff=0.125 beta=4.5`。

### 结果

- 遗忘后模型与评估写入 `${save_dir}/`
- 汇总指标：`${save_dir}/checkpoint/aggregate_stat.txt`
- `save_dir` 目录名带 `2GPU_` 前缀，位于 `model_path/unlearned/` 下

## 6. WMDP（可选）

1. 按 [WMDP README](../WMDP/README.md) 下载 WMDP-Bio 数据到 `WMDP/files/data/`（该目录被 gitignore，无法随仓库分发）。

3. 运行：

```bash
cd WMDP
bash run_wmdp_unlearn.sh    # 已改为 CUDA_VISIBLE_DEVICES=0,1
```

单进程 `device_map=auto` 会自动在 2 卡上分片；`SimNPO.json` 关键项：`lr=9.5e-6`、`max_steps=500`、`beta=0.1`、`gamma=1.0`。结果在 `WMDP/files/results/unlearn_wmdp_bio/SimNPO`。

## 8. 常见问题

- `**flash-attn` 编译失败**：把 `TOFU/config/model_config.yaml` 中 `llama2-7b.flash_attention2` 设为 `"false"`（可跑，略慢）。
- **评估阶段 OOM**：进一步下调 `forget.yaml` 的 `eval.batch_size`（如 4）。
- **磁盘写满**：确认 `HF_HOME` 与模型都在数据盘，而非 30GB 系统盘。
- **Llama-2 访问受限**：在 HF 模型页同意 Meta 许可并 `huggingface-cli login`。
- `**model_path` 报错找不到目录**：必须是本地目录，不能填 HF 仓库名。

---

## 9. 时间预估

相较论文 8 卡，2 卡吞吐约为其 1/4，墙钟时间约 **4 倍**。用 `accum=16` 对齐全局 batch 不会显著增加耗时，主要瓶颈是卡数。
