# SimNPO 方法原理与代码对照

本文档梳理 SimNPO 的底层逻辑、公式推导与仓库中的实现位置，供读代码/改方法时对照。跑实验的步骤见 [复现指南](复现指南.md)。

> 说明：为保证在各类 Markdown 渲染器下显示一致，公式一律用纯文本代码块，不使用 LaTeX。符号约定：`π_θ` 当前模型，`π_ref` 参考模型（遗忘起点），`σ` sigmoid，`D_f` 遗忘集，`D_r` 保留集，`|y|` 答案的有效 token 数。

---

## 1. 问题设定

给定已在全量数据上微调好的模型 `π_ref`（本仓库即 `locuslab/tofu_ft_llama2-7b`），将数据切成遗忘集 `D_f` 与保留集 `D_r`，求 `π_θ` 使其满足：


| 目标                  | 含义                          |
| ------------------- | --------------------------- |
| 遗忘质量 forget quality | 在 `D_f` 上的行为接近"从未见过这些数据"的模型 |
| 模型效用 model utility  | 在 `D_r` 与通用能力上不掉点           |


**黄金标准是"只在 `D_r` 上重训得到的 retain model"，不是"遗忘集概率越低越好"。** 把遗忘集概率压到零属于过度遗忘，同样算失败。这一点直接决定了第 6 节的评测方式。

---

## 2. 方法演化谱系

`TOFU/dataloader.py` 的 `compute_loss`（第 148–428 行）把整条路线都实现了，可当对照表读。


| 代际  | 方法              | 损失                    | 主要问题                 |
| --- | --------------- | --------------------- | -------------------- |
| 1   | GA 梯度上升         | `-L_CE(D_f)`          | **无下界**，可发散至负无穷，模型崩塌 |
| 2   | GradDiff / KL   | `-L_f + L_r`          | 只延缓发散，未解决根因          |
| 3   | DPO / IDK / KTO | 偏好优化，偏好"我不知道"         | 需构造正样本，污染通用行为        |
| 4   | NPO             | 只保留 DPO 的 rejected 项  | 参考模型偏置（第 4 节）        |
| 5   | **SimNPO**      | 去参考模型 + 长度归一 + margin | 本文方法                 |


第 3 代对应仓库的 `TextForgetDatasetDPOQA` 与 `TOFU/data/idontknow.jsonl`。

## 3. NPO：自适应梯度权重

```
L_NPO = (2/β) · E_{(x,y)∈D_f} [ -log σ(β·u) ]

其中  u = -log( π_θ(y|x) / π_ref(y|x) )        # 当前 NLL 减参考 NLL
```

代码中 `neg_log_ratios` 即 `u`，见 `TOFU/dataloader.py` 第 292–306 行。对 θ 求导得：

```
∇_θ L_NPO = w · ∇_θ log π_θ(y|x)

其中  w = 2·σ( β · log( π_θ / π_ref ) )        # 自适应权重
```

梯度下降沿 `-∇log π_θ` 走，即压低遗忘样本似然。关键在权重 `w`：

- 起点 `θ = ref` 时 `w = 1`，等价于 GA；
- 随遗忘推进 `π_θ` 下降，`w → 0`，梯度自动熄火，避免灾难性发散。

`β → 0` 时 NPO 严格退化为 GA，即 **GA 是 NPO 的极限特例**。

## 4. 核心诊断：Reference Model Bias

### 4.1 权重只看相对增量

令样本在参考模型下的 NLL 为 `a`、当前模型下为 `b`，则

```
w = 2·σ( -β·(b - a) )
```

**权重只依赖增量 `b - a`，与绝对遗忘水平 `b` 无关。** NPO 因而对所有样本要求同样的*相对*遗忘量，而非同样的*绝对*遗忘水平：


| 样本类型      | 参考模型 NLL     | 结果                         |
| --------- | ------------ | -------------------------- |
| ref 本就记不牢 | `a` 大（如 5）   | 被推到 `5+Δ`，**过度遗忘**，白耗效用    |
| ref 记得很牢  | `a` 小（如 0.1） | 只到 `0.1+Δ` 权重就衰减，**遗忘不彻底** |


遗忘集内部难度参差时失衡显现，即论文所说 "forget data of varying difficulty"。

### 4.2 长度偏置

`get_batch_loss`（`TOFU/data_module.py` 第 280–288 行）对序列内 token 做的是**求和**而非平均：

```python
loss = loss_function(output.transpose(-1,-2), shifted_labels).sum(dim=-1)
```

于是

```
b - a = Σ_t log( π_ref(y_t) / π_θ(y_t) )        # 随长度线性放大
```

长回答的 sigmoid 更早饱和、权重更早归零，**长样本系统性欠遗忘**。

## 5. SimNPO：两处修改

借鉴 SimPO（Simple Preference Optimization）——用长度归一化的平均对数似然作隐式奖励、加 reward margin，从而彻底去掉参考模型：

```
L_SimNPO = (2/β) · E_{(x,y)∈D_f} [ -log σ( β·( NLL_avg - γ ) ) ]

其中  NLL_avg = ( -log π_θ(y|x) ) / |y|         # 长度归一化的平均负对数似然
```

梯度权重变为

```
w = 2·σ( -β·( NLL_avg - γ ) )
```

判据是**绝对量**且**与长度无关**，第 4 节两处偏置同时消失。`γ` 显式指定"遗忘到什么绝对水平就停"。

实现只有两处改动（`- self.gamma` 与 `/ loss_mask.sum(-1)`），见 `TOFU/dataloader.py` 第 269–276 行：

```python
loss_mask = labels != -100
forget_loss = get_batch_loss(outputs.logits, labels) / loss_mask.sum(-1) - self.gamma
loss = -F.logsigmoid(self.beta * forget_loss).mean() * 2 / self.beta
```

> 注：代码中 `γ` 作用在归一化 NLL 上，与论文公式的 `γ` 相差一个 `β` 缩放。主实验 `γ = 0`，无影响。

主实验用带保留项的 `simnpo_grad_diff`（第 278–289 行），对齐论文式 (1) `ℓ_f + λ·ℓ_r`：

```
L = npo_coeff · L_SimNPO + grad_diff_coeff · L_CE(D_r)
# 论文：npo_coeff=1.0，grad_diff_coeff=λ（forget05: 0.1375，forget10: 0.125）
```

**训练时不需要参考模型前向**，相比 NPO 每步省一次 7B forward。仓库仍加载 `oracle_model`，仅因评估阶段要算相对 oracle 的 KL 散度（`dataloader.py` 第 68 行无条件调用 `e_prepare_deepspeed`），这也是显存偏高的原因之一。

## 6. TOFU 训练与评测

### 6.1 数据与训练


| 环节   | 实现                                                                                |
| ---- | --------------------------------------------------------------------------------- |
| 数据配对 | `TextForgetDatasetQA.__getitem__` 每次返回 (第 `idx` 条 forget, 随机抽的 retain)            |
| 批处理  | `custom_data_collator_forget` 堆成两组张量交给 `compute_loss` 解包                          |
| 标签掩码 | `convert_raw_data_to_model_format` 把问题与 padding 的 label 设为 `-100`，损失只在答案 token 上算 |
| 步数   | `max_steps = num_epochs × len(dataset) / (batch_size × accum × world_size)`       |


SimNPO 分母 `loss_mask.sum(-1)` 数的就是这些有效答案 token。

论文主设定超参：


| 设置       | beta | npo_coeff | gamma | grad_diff_coeff (=λ) |
| -------- | ---- | --------- | ----- | -------------------- |
| forget05 | 2.5  | 1.0       | 0.0   | 0.1375               |
| forget10 | 4.5  | 1.0       | 0.0   | 0.125                |


`β` 控制 sigmoid 陡峭程度即权重衰减快慢；遗忘比例越大用越大的 `β`（更保守）。`λ=grad_diff_coeff` 乘在保留 CE 上（论文式 1），不是乘在 SimNPO 项上。

### 6.2 评测：为什么 Forget Quality 是个 p 值

**Truth Ratio** 是核心统计量：对每个问题比较模型对"改写的正确答案"与"扰动的错误答案"的困惑度之比，

```
R = exp( 平均扰动答案 loss - 平均改写答案 loss )
```

`R` 大说明模型仍偏好正确答案。

**Forget Quality** 用 KS 双样本检验比较 unlearned 与 retain 模型在遗忘集上 Truth Ratio 的**分布**，取 p 值（`TOFU/utils.py` 第 143–160 行）。**p 值越大越好**——大 p 值意味着统计上无法区分你的模型与真正重训的模型。这正好呼应第 1 节：过度遗忘会让分布偏离 retain 模型，p 值反而下降。仓库预置的 `TOFU/data/retain*_llama_wd0.01/` 即各比例下 retain 模型的评测结果，作为对照分布。

**Model Utility** 是 3 个数据集（Retain / Real Authors / Real World）× 3 个指标（ROUGE-L recall、答案概率、Truth Ratio）共 9 个数的**调和平均**。用调和平均是为了惩罚短板，任一项塌了整体就塌。

## 7. WMDP 与 synthetic

**WMDP**：Zephyr-7B 遗忘生物危害知识，检验"能力遗忘"而非"事实遗忘"，并测 relearning attack 鲁棒性。实现与 TOFU 有两处差异（`WMDP/src/unlearn/GA.py` 第 106–133 行）：

- 直接用 HuggingFace 的 `outputs.loss`（整 batch 所有有效 token 的平均），是 batch 级近似，而非 TOFU 的逐样本归一化后取均值；无 margin 项。
- `**gamma` 在这里是保留项系数，与 TOFU 中作为 margin 的 `gamma` 完全不同**。`SimNPO.json` 的 `gamma: 1.0` 对应 TOFU 的 `grad_diff_coeff`，读配置勿混淆。

**synthetic**：理论验证。`data_generation.py` 构造三条状态互不相交的马尔可夫链（retain / forget1 / forget2），用 `leakage` 控制跨子集转移概率，在混合数据上预训练小 Transformer。真实转移矩阵已知，可精确计算遗忘后模型与 retain 分布的 KL，在可控环境下验证"NPO 因难度差异遗忘不均衡、SimNPO 更均衡"。`unlearn_utils.py` 中 `NPO_loss` 与 `SimNPO_loss` 的唯一差别就是那行 `/ valid_mask_f.sum(dim=1)`。

## 8. 易踩的实现细节

- `forget.py` 用 `os.listdir(cfg.model_path)` 探测权重，`**model_path` 必须是本地目录**，不能填 HF 仓库名。
- `simnpo` 分支只解包 forget 一路（`forget_inputs, _ = inputs`），retain 被丢弃；要保效用必须用 `simnpo_grad_diff`。
- `interleave_eval_result_dict`（`TOFU/utils.py`）源码注释已声明**只支持 2 个进程**，且硬编码 `small_bsz = large_bsz // 4`。改 `eval.batch_size` 须保证能被 4 整除（当前 8，安全）；卡数超过 2 会导致评测结果错乱。
- `forget.yaml` 设 `evaluation_strategy="no"`，训练中途不评测，仅在 `trainer.train()` 后调一次 `trainer.evaluate()`，结果落在 `${save_dir}/checkpoint-{step}/aggregate_stat.txt`。
